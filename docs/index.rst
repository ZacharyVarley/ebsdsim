ebsdsim documentation
=====================

**Dynamical EBSD master-pattern simulation for Python.**

``ebsdsim`` computes Lambert-projected Kikuchi master patterns from crystal
structures using multi-beam dynamical electron diffraction on the GPU via WebGPU.
Output is raw dynamical intensities; display scaling is applied on demand.
